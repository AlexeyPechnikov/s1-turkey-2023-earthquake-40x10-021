# s1-turkey-2023-earthquake
Geocoded and preprocessed Sentinel-1 SLC data for the 2023 Turkey earthquakes (InSAR.dev)

The dataset is produced by InSAR.dev preprocessor, and it is intended to be used for cloud-native InSAR processing in InSAR.dev software. Alternatively, you can download it to work locally.
